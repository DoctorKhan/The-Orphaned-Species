# SERIES STRUCTURE — the authoritative volume map

> **Read this first if you are unsure how many books this series has, what's in each one, or what a file name refers to.** This project was restructured from four volumes to five on **2026-07-29**, by splitting the original 13-chapter Book I into two. If any other document (including this project's own planning files) states a volume count, chapter count, or cross-book reference that conflicts with this file, **this file wins** until that document is updated.

**What actually changed:** only Book I. It was split at the end of its original Chapter Three ("What Didn't Die" — Eli's "I'm not going dark" decision), which is now where Book I ends. Chapters Four through Thirteen (the Thailand agricultural-witness sequence and the Sanxingdui/Rasel-rescue climax) became a new Book II, renumbered internally as Chapters One through Ten. **No prose was rewritten** — only split, renumbered, and given new front-matter headers.

**What did not change:** the content of the old Books II, III, and IV. Each simply moved up one slot in the numbering (old II → III, old III → IV, old IV → V) and got its file renamed and its title header updated to match. Read any of them exactly as before; only the Roman numeral changed.

## Why this exists

Before the split, Book I (42k words) was nearly three times the length of Book IV (14.8k) — a real imbalance across the series. The split brings the five volumes to a much more even spread (17k / 25.5k / 29.9k / 23.9k / 14.8k) and gives the Thailand sequence its own volume identity instead of functioning as the back two-thirds of a book titled "The Breach," which described only its first third.

## For future sessions (human or AI)

- If a document says "Book II" and means Albion/Wren-Rowan/the Charkha reveal/Maren's rescue at Albion — that content is now **Book III**.
- If a document says "Book III" and means the network/Hawaiʻi/federation arc, Sol, the Extras/cloisters, the attacked council — that content is now **Book IV**.
- If a document says "Book IV" and means the women-led court-intrigue volume, Rowan/Eli's romance, the birth/succession climax — that content is now **Book V**.
- If a document says "Book I" and describes anything from the Thailand sequence onward (Wren's boat trip, Malai's cooperative, Khun Dang's lodge, Sanxingdui, Rasel's rescue) — that content is now in **Book II**, not Book I.
- Reference docs, beatsheets, and locks elsewhere in the project (`WORLD_BIBLE.md`, `00_MASTER_TIMELINE.md`, the numbered beatsheets, etc.) have **not** been mass-updated to the new numbering — that would risk more errors than it fixes in one pass. They are being corrected as they're touched, per this project's own standing practice of fixing patterns directly rather than spraying cross-references. If you find an unconverted "Book II/III/IV" reference elsewhere, translate it using the table above rather than assuming it's wrong or reverting it.
